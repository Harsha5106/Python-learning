# Day 15: NLP Text Preprocessing

This exercise preprocesses a small sample corpus with NLTK. It lowercases and
tokenizes the text, removes stopwords and punctuation, and applies Porter
stemming. It prints the raw and cleaned token lists and their counts for
comparison.

The stopword list is included in `main.py`, so running the program does not
require downloading NLTK data files.

## Run

From the project root, install the dependency and run the example:

```powershell
python -m pip install -r WEEK_03\Day_15\requirements.txt
python WEEK_03\Day_15\main.py
```
